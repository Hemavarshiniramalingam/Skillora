# Skillora Frontend

This project is a Django-based frontend prototype for the OpportunityAI student opportunity platform.

## Setup

```bash
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install django
python manage.py migrate
python manage.py runserver
```

## Features

- Student dashboard with readiness score and top matches
- Internship listing and detail pages
- Scholarship listing and detail pages
- Profile page
- Application tracker board
- Responsive Bootstrap layout using hardcoded sample data
